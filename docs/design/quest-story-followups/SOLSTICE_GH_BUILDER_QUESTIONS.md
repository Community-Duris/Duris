# solstice_gh builder questions and recommended resolutions

Checkpoint 532, source snapshot `c500ac51b8cd26540943257e7ca4e9807263ef74`.
These questions concern the unlisted Solstice Guild map, its Torg and
unlisted same-number identities, the Duris3 outlet, imported objects, code
binding, and possible full-mode shop fallback. They do not authorize
activation, source changes, movement, merging, or archiving.
