# `tiamats_lair` builder and manifest-owner questions

The 2012 source swap makes Azhural the selected world version, while `qst/AREA` still selects the byte-identical legacy QST file. These questions keep those paths and the mixed record identity explicit. See [TIAMATS_LAIR_AUDIT_REVIEW.md](TIAMATS_LAIR_AUDIT_REVIEW.md) and [AZHURAL_AUDIT_REVIEW.md](AZHURAL_AUDIT_REVIEW.md).

1. **Source owner:** Who owns the remaining `tiamats_lair` WLD/MOB/OBJ/ZON/QST paths? **Recommendation:** retain all five until their data and manifest owners are known.
2. **Replacement commit:** Does commit `50b400005` remain the authoritative record that Azhural replaced the old world source? **Recommendation:** preserve the explicit history and keep Azhural selected in `areas/AREA`.
3. **QST manifest:** Why does `qst/AREA` still select `tiamats_lair.qst` while it omits `azhural.qst`? **Recommendation:** have the QST manifest owner decide the supported source path before changing either entry.
4. **QST source of truth:** Which path should future QST edits use when both files are byte-identical today? **Recommendation:** keep the selected old path intact until one canonical source is documented and the list is reconciled.
5. **Generated QST:** Has the current QST aggregate been built from the checked-in manifest, and which deployment consumes it? **Recommendation:** verify the generator and deployment inputs before any archive decision.
6. **Gate contract:** Is the first contract's eight-bone-shard key exchange still the intended wording and item flow? **Recommendation:** preserve its current text and item commands until its quest owner confirms the contract.
7. **Archway contract:** Is the second contract's five dragon-flight essences requirement still intended? **Recommendation:** retain its current text and item commands while its source path is reconciled.
8. **QST giver owners:** Should givers #135219 and #135220 continue to be supplied by active Azhural prototypes while the QST source path stays under `tiamats_lair`? **Recommendation:** retain the exact IDs and verify ownership with the Azhural and quest owners.
9. **WLD body matches:** What history explains 41 exact and 42 changed room bodies across the 83 shared room IDs? **Recommendation:** preserve both records and use the replacement history to distinguish old-map text from current Azhural.
10. **MOB body matches:** What is the intended owner for the five exact and fifteen changed same-number MOB bodies? **Recommendation:** do not merge or co-load either prototype set until its reset/runtime ownership is confirmed.
11. **OBJ duplicates:** Since all 38 legacy object records exactly match Azhural, should the legacy OBJ file remain as historical source evidence? **Recommendation:** retain it while the old zone and QST manifest paths are reviewed; do not delete it based on byte equality alone.
12. **Legacy reset set:** Are the 16 old M resets and one O reset preserved only for the superseded map? **Recommendation:** keep them outside the active world list and do not import them into the Azhural ZON.
13. **Reset delta:** Who owns the difference between the old 17-command ZON and the current 129-command Azhural ZON? **Recommendation:** preserve each version's reset file and document any later comparison separately.
14. **Portal definitions:** Should old objects #135230/#135231 remain byte-identical copies of active Azhural's portal prototypes? **Recommendation:** preserve the legacy OBJ entries and treat placement only through the active Azhural ZON.
15. **Portal target identity:** Do the legacy portal targets #135275/#135202 remain meaningful only as same-number Azhural rooms? **Recommendation:** do not infer a second legacy portal route from the copied object values.
16. **Map/editor data:** Is there an external editor or export representation for the old 83-room map despite no checked-in `areas/map/tiamats_lair.json`? **Recommendation:** ask the map/tool owner before removing or renaming any source path.
17. **Story boundary:** Should the two legacy-path QST contracts remain attached to the active Azhural story sidecar? **Recommendation:** preserve the separate source inputs and ask the story/quest owner before editing their relationship.
18. **Persisted identity:** Are any deployed quest progress records or editor references keyed to the legacy QST filename or giver IDs? **Recommendation:** verify persistence and tool references before a filename or manifest change.
19. **Historical disposition:** Does the explicit world-version swap authorize archiving the non-QST files, or should they remain historical sources? **Recommendation:** treat the swap as world membership history only; retain the full source family while the live QST path remains unresolved.
20. **Disposition authority:** Who can authorize reconciling `qst/AREA` and retiring the legacy path? **Recommendation:** retain `tiamats_lair.qst` and its companion sources until a separate documented owner decision is made.
