# Vehicles builder questions and recommendations

The [source story review](../quest-story-followups/VEHICLES_STORY_REVIEW.md)
maps the local 255 Q/QA contracts, the shipboard factions, and Kjelgar's
crafting inputs. The ferry implementation also defines seven moving vessels
with named external stops. This checklist makes twenty source-backed builder
decisions explicit. It does not authorize gameplay edits or certify that a
configured path, ticket, reset, reward, or hazardous passage works in play.
See [coverage row 337](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L337).
