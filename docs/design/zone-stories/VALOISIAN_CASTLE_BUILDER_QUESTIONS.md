# The Valoisian Castle builder questions and recommendations

The [source-comprehensive Valoisian Castle dossier](THE_VALOISIAN_CASTLE.md)
records all eight native item exchanges, local access and stock, unfinished
areas, and bounded external references. The [Checkpoint 45 audit supplement](../quest-story-followups/VALOISIAN_CASTLE_AUDIT_REVIEW.md)
records the active Surface boundary, one source-only inbound WLD record,
typed references, and title/history findings. These twenty questions make
remaining builder choices explicit without treating static records as proof
of live availability or player completion. See [coverage row 331](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L331).
