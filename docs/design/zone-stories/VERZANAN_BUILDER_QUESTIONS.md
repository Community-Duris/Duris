# Verzanan builder questions and recommendations

The [source story and dependency review](VERZANAN_STORY_REVIEW.md) maps the
two-room bookend WLD, 158 local mobile prototypes, 180 local object
prototypes, disabled legacy assignments, and extensive outside use of local
objects. These twenty questions identify source decisions for the area owner.
They do not authorize changes to native files, player routes, or gameplay.
See [coverage row 339](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L339).
