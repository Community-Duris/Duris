# The Unique's Vault source-backed builder review

Active `unique` is an object-owner contributor with 84 object prototypes
(#67200–#67283) and two rooms. Its WLD joins #67200 and #67300 as a reciprocal
down/up pair: the first room says `world o` displays the objects, and the
second is described as a bookend so their object details display correctly.
The source inventory records no mobile prototypes, local QST or SHP, and no
story sidecar. `unique` is listed in both [areas indexes](../../../areas/AREA#L254)
and the [quest index](../../../areas/qst/AREA#L228). The local ZON file has no
reset commands. See [coverage row 328](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L328).

Three external G resets are highlighted in this story review: Astral Main imports #67206, New Cave city imports #67272, and Swamp Two imports #67238. They are examples, not a complete consumer inventory: Checkpoint 870 found 42 active external ZON reset commands across 38 active area owners, all importing prototypes still owned by Unique. Four more commands occur only in the existing Brass Old 1, Brass Old 2, and Nexus56 candidate sources. See the [bounded typed dependency review](../quest-story-followups/UNIQUE_AUDIT_REVIEW.md). Reset commands document authored source intent; they do not establish current stock or availability.

## Source review closure

The narrative pass reviewed both room records and all 84 object prototypes.
The second room is a display bookend, the mobile file is empty, and the local
zone file contains no resets. The object lore ranges from uncertain powers and
repeated golden-token redemption wording to references to Kazz'Ani and
Quturac's Cave City conflict, Valran and Arbre, Dreggan Wood, Euronymous and
Erebus, Thrym and Utgard-Loki, Tinytoes, Minthka guardians, and Tezcatlipoca.
These are separate item histories; the local source does not place them in the
vault or define their implied cross-area stories as local encounters or
transactions. Three non-token objects also carry a `token token unique`
extra-description key, so their redemption text needs separate review.
