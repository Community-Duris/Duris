# Vargan builder questions and recommendations

The [source-comprehensive Vargan dossier](VARGAN.md) and [Checkpoint 104
audit supplement](../quest-story-followups/VARGAN_AUDIT_REVIEW.md) map the
hidden armor pieces, Norkon's mixed exchange, local routes, and external
boundaries. This checklist makes twenty direct-source builder decisions
explicit while preserving the documented limit that the paid exchange is
currently unavailable under active accounting. It does not authorize a runtime
change or certify played outcomes. See [coverage row 335](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L335).
