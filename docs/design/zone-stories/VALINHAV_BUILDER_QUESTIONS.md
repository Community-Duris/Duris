# Valinhaven builder questions and recommendations

The active [Valinhaven area source set](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L333)
contains room, mobile, object, and reset files; its QST directory entry is a
membership record, not a local quest contract. No local shop source or story
sidecar is inventoried. These questions separate authored setting and encounter
text from services, quest outcomes, hazards, and access guarantees that the
sources do not establish. See the [source narrative review](VALINHAV.md) for
the setting overview. Neither document certifies live gameplay.
