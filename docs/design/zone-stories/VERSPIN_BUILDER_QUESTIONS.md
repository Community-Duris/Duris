# Verspin builder questions and recommendations

The [comprehensive source story map](VERSPIN.md) covers all 52 native QST
blocks, twelve exact exchanges, eighteen addressed contacts, the 200 room map,
and its reset/source families. This checklist makes twenty direct-source
builder decisions explicit while preserving that evidence map. It does not
authorize changes to native stories, services, access, accounting, or gameplay
and does not certify any journey in play. See [coverage row
338](../quest-story-followups/ZONE_COVERAGE_REGISTER.csv#L338).
