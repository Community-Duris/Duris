Seeding is skipped on successful Redis world recovery and repeated after a
failed recovery falls back to normal zone boot. It places the external first
fragment before checking whether the automaton exists; partial seed failure
therefore needs an idempotent accepted-source design. Ship core issuance is
custom, not an ordinary object reset. The core has no fragment special callback;
only a root-carried fragment runs assembly, and bagged or equipped parts do not
count in its root scan. A second core takes the current `TODO: something nasty`
branch and returns without assembly; this is unfinished behavior, not evidence
that a penalty exists. Normal two-fragment/one-core assembly removes all parts
before checking the output prototype/allocation, so failure ordering needs
repair/qualification before a new persistent stage can be credited.

Erzul prioritizes any broken part over a finished heart and attacks its carrier.
The handler splits the ask argument but does not validate the named recipient
against Erzul. Generic dispatch visits special mobiles before native quest
handlers. Thus a different addressed ask in his room can trigger his response,
attack or reward/crew branch. Do not reuse an ask attempt as a learned-topic,
hostility or settlement receipt. Xexos's admission is similarly based on current
fragment custody, not a recorded personal automaton kill; combat transforms
him into Agthrodos while transferring inventory/equipment. Those transformations
need a shared source-instance lineage if integrated later.

The ring and crew are alternative uses of one finished stone. A foreign
[Winterhaven commission](../../../areas/qst/wh.qst#L2199), Ohnagra 55127,
also consumes moonstone 12001 plus explorer gloves 20949 and green potion
20950 for reward 55062. Its receipt stays foreign-owned and does not prove
Erzul was rewarded. Assembly history never replaces a stone already spent at
any of these recipients. No accounting guard is removed here; custom output
and payment paths are unqualified even if an old matching stone survives.
