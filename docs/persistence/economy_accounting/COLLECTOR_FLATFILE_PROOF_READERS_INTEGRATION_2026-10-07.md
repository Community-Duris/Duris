accepting a structurally valid generic accounting record. Rejected operations
must have an empty reference set. It can recover an existing authority journal
under the caller's lock; it never applies an absent operation.

the active epoch/lifetime mappings, current wallet/shared bank, listing, owner

wallet revisions or item literals refuse; a later shared-bank revision follows
the existing SQL policy. Neither reader provides a publication capability.

Exactly five qualified source/test files are imported. The original common
unavailable-world fixture stays unchanged. Three unavailable world functions
live in a dedicated component-only translation unit and abort on every call;
they never return successful proof. Existing original assertions, compiler and
runtime arguments, flags, temporary-directory behavior and limits remain intact.
The wrapper changes only its thirteen additional source entries.
