## Implementation and scope

`--scope physical-namespace` captures raw direct filenames under the existing
read-only authority lock into external private operator files. One live stream
captures at most 2,198,786 names and 128 MiB of encoded inventory; the combined
context/name reads have their own 128 MiB/16,384-read/30-second admission bound.
Large sources can refuse admission. Nothing is silently truncated. Protected
chunks contain at most 128 names, with offset/count/length/SHA256 metadata under
4 MiB. Progress is at most 32 KiB and binds the root, executable, operator code,
metadata and inventory file identity. Source cuts also bind the economic
directory's identity and change/modification metadata. No persistent directory
cookie or assumed cross-process directory ordering is used.

Each subsequent invocation authenticates one chunk and independently checks one
filename's reverse association. Authority indexes, common indexes/segments,
baseline heads/reservations/witnesses, lifecycle receipts and source claims use
the existing independent decoders and original authority/root bytes. Reserved
malformed filenames or unassociated physical files become sticky findings;
other filenames are counted as ignored. Default physical read, byte and time
budgets remain exact; the Python subprocess timeout remains 45 seconds. The
native budget probe separately measures the selected reverse-check subroutine
after establishing context, and forces real file/byte/deadline refusals.

Only `known_physical_economic_namespace_closed` can become positive after all
captured entries pass. It proves reverse association of the captured files,
not forward completeness, consecutive baseline history, every mapping
cross-link, unknown initialization provenance, complete source history or
current holdings. `complete`, `consistent_entire_sweep`,
`orphan_namespace_closed`, `baseline_books_closed`, `native_holdings_compared`
and `release_qualified` stay false. A protected, quiescent restored image is
required for a stable snapshot; these pages do not establish atomic live health.

A changed source cut or global native refusal preserves the cursor and keeps
findings sticky. A typed selected-file quota refusal advances with an invalid
file finding and cannot earn closure. Closed checkpoints start another complete
bounded traversal, rather than reusing prior positive results after in-place
damage. Interrupted file progress retries the same captured entry. Interrupted
initial publications preserve unclaimed auxiliary artifacts and require a fresh
path. Existing auxiliary files are never silently overwritten. The native
capture descriptor must be empty/private/single-link/outside the authority tree.
No native mutation, journal recovery, finding correction or activation runs.
